# Novolis.Workspaces.DotNet.Slnx

Read-only physical topology projection for modern `.slnx` files.

## Install

```powershell
dotnet add package Novolis.Workspaces.DotNet.Slnx
```

## Quick start

`SlnxSolutionReader` reports solution folders, project paths, and typed diagnostics without
rewriting the source solution file.
